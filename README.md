# EatRaiD: Smart Food & Restaurant Recommendation Platform

**EatRaiD** is a web/mobile application designed to solve the ultimate daily dilemma: *"What should I eat?"* The platform provides intelligent food and restaurant recommendations, dietary restrictions, or randomized fun wheels to make dining decisions quick, easy, and enjoyable.

---

## Key Features

* **Interactive Randomizer Wheel:** A fun, interactive feature to help undecided users pick a meal instantly.
* **Restaurant Discovery & Filtering:** Allows users to filter food options by category, distance, price range, and dietary preferences.

---

## System Architecture

1. **User Interface (Frontend):** A visually appealing interface optimized for desktop
2. **Backend Services (API):** Manages user authentication and fetches restaurant data.
3. **Database Management:** Stores structured information regarding menus, user profiles, and restaurant locations.

---

## Tech Stack

* **Frontend:**  Next.js 
* **Backend:** Node.js(Express)
* **Database:** supabase
